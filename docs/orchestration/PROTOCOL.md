# Execution protocol

1. Select task (DEPENDENCY_MAP). 2. Load its CONTEXT_MAP row. 3. Inspect existing code. 4. Confirm interfaces. 5. Smallest complete implementation. 6. Add tests. 7. Run targeted tests (full suite at milestones). 8. Review (`code-review` skill for non-trivial diffs). 9. Update docs: step Status, RUHAN_CHECKLIST, README (orchestrator), encyclopedia. 10. Log decisions in DECISIONS.md. 11. Update STATE.md and write a concise handoff.

Status words: Not started · In progress · Implemented but unverified · Blocked · NEEDS REVIEW (ready; Ruhan approves) · Verified complete (only after Ruhan's approval and passing gates).
