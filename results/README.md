# Experiment results

Everything here is generated by `python -m traceforge.evaluation.runner` and is git-ignored except this file (commit results only after checking size and what they contain).

- `official/<run_id>/`: official research runs. Provider `axforge`, model `glm-5.3-flash` only. `meta.json`, `records/<case>.r<k>.json` (AgentRunRecord), `cases/<case>.r<k>/` (patch.diff, diagnosis.json, trace.json, repair.json, run_meta.json).
- `development/<run_id>/`: development runs (any other provider/model, for example BeatAPI `glm-5.3-flash-free`). **Never** mixed into official tables.
- Token ledgers (provider-reported usage, never reset): `runs/axforge_usage.jsonl` (ceiling 2,400,000), `runs/beatapi_usage.jsonl` (development, no ceiling). Summary: `python -m traceforge.evaluation.usage_report`.
- Records are written immediately after each case; a rerun with the same `--run-id` skips finished cases and cases without inputs (no evidence bundle), so a crash loses at most the case in flight. Hidden-test names/outputs are never written, only pass/fail counts.
